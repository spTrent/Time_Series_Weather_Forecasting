# Weather Forecast - Прогноз температуры по городам России

Проект по прогнозированию температуры воздуха на 7 дней вперёд для 6 российских городов с помощью методов машинного обучения.

## Описание

Анализ почасовых метеоданных и построение многошагового прогноза температуры (`Direct` подход) на основе трёх моделей: Decision Tree, Random Forest и XGBoost. Включает полный цикл: загрузка и очистка данных -> EDA -> анализ временного ряда -> инжиниринг признаков -> обучение и отбор модели -> оценка на тестовой выборке.

## Данные

Источник: файл `have_fun.xlsx` (3 листа, объединяются в один датафрейм).

Признаки:
- `ds` - временная метка (часовая гранулярность)
- `city` - город
- `temperature_2m` - температура на высоте 2 м (целевая переменная)
- `relative_humidity_2m` - относительная влажность
- `precipitation` - осадки
- `rain`, `snowfall` - дождь и снегопад
- `weathercode` - код погодного явления
- `wind_speed_10m` - скорость ветра
- `surface_pressure` - давление на поверхности

## Пайплайн

### 1. Загрузка и объединение данных
Три листа Excel читаются и объединяются в единый датафрейм.

### 2. Очистка данных
- Исправление кодировки кириллицы (latin1 -> cp1251)
- Нормализация названий городов (опечатки, регистр)
- Исправление нечисловых значений в метеопризнаках (замена текстовых кодов погоды на числовые по WMO)
- Заполнение пропусков: линейная интерполяция для температуры, давления, влажности; forward fill для ветра, осадков, weathercode
- Удаление выбросов по физическим диапазонам (например, температура вне [-30, +40]°C)
- Удаление выбросов в температуре методом скользящего z-score (окно 24 ч, порог 3 std)

### 3. EDA и анализ временного ряда
- Гистограммы + boxplot для всех числовых признаков
- Визуализация температурных трендов по городам
- Скользящее среднее и стандартное отклонение (окно 720 ч)
- Тест Дики–Фуллера (ADF) на стационарность
- ACF / PACF (дневная и месячная гранулярность)
- Анализ Фурье - выявление периодичностей
- Вейвлет-скалограмма (cwt, `cmor1.5-1.0`) - подтверждение годовой и суточной сезонности
- STL-декомпозиция (тренд + сезонность + остаток)

### 4. Инжиниринг признаков
| Группа | Признаки |
|---|---|
| Лаги температуры | lag_1, lag_2, lag_3, lag_24, lag_8760 |
| Цикличное кодирование времени | month_sin/cos, day_of_year_sin/cos, hour_sin/cos |
| Разности | diff_1_hour, diff_1_day |
| Давление | press_lag_3, press_diff_3h |
| Скользящие по осадкам/ветру | precip_sum_24h, wind_mean_3h |
| Скользящие по температуре | roll_mean/std/max/min за 3 ч и 24 ч |

Город кодируется через OneHotEncoder.

### 5. Разбивка данных

| Выборка | Период |
|---|---|
| Train | до 31.12.2023 |
| Validation | 01.01.2024 – 31.12.2024 |
| Test | с 01.01.2025 |

### 6. Модели и обучение

Используется **Direct** стратегия: отдельная модель на каждый день горизонта (1–7 дней).

| Модель | Оптимизация гиперпараметров |
|---|---|
| Decision Tree | Optuna (50 trials) |
| Random Forest | Optuna (15 trials) |
| XGBoost | Optuna (50 trials) |

Также реализован **рекурсивный** прогноз на основе лучшей модели XGBoost.

Каждая модель сравнивается с наивным бейзлайном (прогноз = текущее значение температуры).
